# আফফান লাবীব — খেরোখাতা (Affan Labib's Literary Haven)

> **চিন্তা ও পাঠের নিভৃত আঙিনা**  
> লাইভ ওয়েবসাইট: [affan-labib-blog.vercel.app](https://affan-labib-blog.vercel.app)

---

## 🌟 পরিচিতি (Overview)
এটি লেখক ও গবেষক **আফফান লাবীব**-এর ব্যক্তিগত সাহিত্যিক ব্লগ ও পড়ার খেরোখাতা। এখানে চিন্তা, পাঠালাপ, ইতিহাস, বই-আলোচনা এবং আরবি সাহিত্যের ধ্রুপদী অনুবাদসমূহ প্রশান্ত নান্দনিক আবহে উপস্থাপিত হয়েছে।

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)
- **ফ্রেমওয়ার্ক:** [Astro v5](https://astro.build/) (Static Site Generation - SSG)
- **সিএসএস ও ডিজাইন:** [Tailwind CSS](https://tailwindcss.com/)
- **ফন্ট ও টাইপোগ্রাফি:** `Hind Siliguri` (বাংলা ফন্ট) & `Amiri` (আরবি ও সাহিত্যিক সেরিফ)
- **মোবাইল ও অফলাইন:** Progressive Web App (PWA) সহ কাস্টম Service Worker v7
- **হোস্টিং ও ডিপ্লয়মেন্ট:** Vercel Edge Network

## ✨ প্রধান ফিচারসমূহ (Key Features)
1. **৩-মোড রিডিং অভিজ্ঞতা:** দিন (Light), সেপিয়া (Sepia - হলুদাভ কাগজের বই পড়ার আবহ), এবং রাত (Dark)।
2. **ইন-সিটু ফুটনোট পপওভার:** লেখায় থাকা যেকোনো টীকায় (`[১]`) চাপ দিলে পেজের তলায় জাম্প না করে স্ক্রিনে ভেসে ওঠে।
3. **উক্তি তোরণ (Literary Quotes):** স্বয়ংক্রিয় প্রগ্রেস বারসহ ঘূর্ণায়মান সাহিত্যিক বাণী ও লাইক/হার্ট সিস্টেম।
4. **বিষয়ভিত্তিক লাইভ ফিল্টারিং:** শূন্য রিলোডে চিন্তা, পাঠালাপ, ইতিহাস, বই-আলোচনা এবং অনুবাদের লেখা ফিল্টার।
5. **ব্যক্তিগত বুকশেলফ:** পঠিত বইয়ের রিভিউ ও উইশলিস্ট ট্র্যাকার।
6. **লেখক স্টুডিও (`/admin`):** পিন সুরক্ষিত অফলাইন মার্কডাউন রাইটার ও ডেটা এক্সপোর্টার।
7. **পুর্ণাঙ্গ এসইও ও সোশ্যাল শেয়ারিং:** অ্যাবসলিউট ওপেন গ্রাফ (OG) ইমেজ, টুইটার কার্ড ও Schema.org JSON-LD।

## 🚀 লোকাল ডেভেলপমেন্ট (Local Setup)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build

# প্রোডাকশন বিল্ড প্রিভিউ করুন
npm run preview
```
